# ADR 0001: Gekozen stack

## Context
MVP in 7 dagen, 1 dev, herbruikbaar voor meerdere welzijnsorganisaties.

## Beslissing
Next.js 15 + Supabase + Vercel + Tailwind/shadcn + Tremor.

## Gevolgen
+ Snel prototyping, gratis tier dekt MVP.
+ RLS geeft veilige multi-tenancy out of the box.
− Vendor-lock-in bij Supabase (acceptabel).
